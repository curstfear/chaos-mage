# Маг Хаоса

Браузерная игра на canvas без сборки и фреймворков. GitHub Pages отдаёт файлы из корня `main` как есть: что лежит в репозитории, то и играется.

## Как устроен код

- Все JS-файлы — обычные `<script>` (не модули), подключены в `index.html` **в строгом порядке**. У них общая глобальная область: константы и функции одного файла видны во всех следующих. `import`/`export` и `type="module"` не использовать — сломается.
- Новый файл — добавить `<script src>` в `index.html` в нужное место: после всего, что он использует **при загрузке**. Внутри функций можно ссылаться на что угодно, если она вызывается уже после загрузки всех файлов.
- `js/main.js` всегда последний: запускает `newGame()` и игровой цикл.

| Папка | Что внутри |
|---|---|
| `js/core/` | утилиты (`$`, `rnd`, `clamp`), настройки, звук, `meta.js` (осколки, монеты, рекорды и прокачка между забегами, `localStorage`), `wardrobe.js` (шмотки мага), `online.js` (общий рейтинг), холст и масштаб, состояние забега, ввод с клавиатуры/мыши (`input.js`) и пальцев (`touch.js`) |
| `js/data/` | руны, миры, пакты, `upgrades.js` — дерево прокачки, `outfit.js` — шмотки. Чистые данные, баланс правится здесь |
| `js/sprites/` | пиксельные спрайты, рисуются кодом в offscreen-canvas |
| `js/game/` | логика: мир и чанки, навыки, урон, враги, питомцы, `update()` |
| `js/render/` | `render()` — кадр игры; `trail.js` — след за магом; `menu-scene.js` — сцена главного меню (маг на рунном круге) |
| `js/ui/` | DOM-окна (`modals.js`), главное меню и дерево прокачки (`menu.js`), гардероб, рулетка, рекорды, установка на экран, HUD (`hud.js`) |
| `css/` | `base` → `hud` → `modals` → `workshop` → `cards` → `menu` → `outfit` → `mobile` (последний переопределяет остальные) |

## Важные соглашения

- **Координаты.** `W`, `H` — размер видимой части мира в игровых единицах, не в пикселях. На телефоне `ZOOM < 1` (камера отъезжает). На холст рисовать через `ctx.setTransform(SCALE, …)`, не `DPR`. Текст на холсте — через `drawText()`, он сам учитывает `TXT`.
- **Ввод.** Направление бега — только через `moveDir()`, точка прицела — через `aimWorld()` (на телефоне это всегда автоприцел по ближайшему врагу, ручного прицела там нет намеренно; тап по экрану — рывок). Не читать `keys`/`mouse` напрямую в игровой логике, иначе на телефоне не будет работать.
- **Подписи управления.** В текстах из JS писать `${KEY('craft')}` / `${KEY('pause')}` вместо «TAB»/«Esc». В HTML — два варианта: `<span class="kb">…</span>` для клавиатуры и `<span class="tc">…</span>` для пальцев.
- **Формы навыков** (`cast()` в `game/skills.js`): обычные снаряды идут через `spawnProj` с `kind: 'bolt'` и общую ветку в `update()`; у особых форм свой `kind` и своя ветка. Формы «в единственном экземпляре» (Призма, Приманка, Печать, Тень) при новом касте заменяют старую, а каст от «Цепи» (`depth > 0`) только продлевает её. У всего, что может размножиться, есть потолок (кляксы ≤ 40, привязи ≤ 3 + Мульти, семена ≤ 3 + Мульти).
- **Миры**: запись в `BIOMES` (`data/worlds.js`) + палитра `PAL` и набор построек `BUILD_SETS` (`sprites/world.js`) + музыка `MUSIC` (`core/audio.js`) + опасность в `hazards()` (`game/world.js`) и `drawProp()` (`render/render.js`) + частицы в `spawnAmbient()`.
- **Прокачка.** Все характеристики забега живут в `PACT` (`pactStats()` в `data/worlds.js`): пакт задаёт базу, `applyMeta()` добавляет бонусы дерева. Новый навык дерева = запись в `UPGRADES` с `apply(P, уровень)` + новое поле в базе `pactStats`, если его ещё нет, + место в игре, где это поле читается. Позиции в ветке — сетка 3×4.
- **Шмотки.** Каталог — `ITEMS` в `data/outfit.js` (слот, способ получения `src`: free / shop / ach / roll, редкость `rar`, параметры вида). Рисует их `sprites/mage.js` (по функции на слот), следы — `render/trail.js`. Что есть и что надето — `WARD` в `core/wardrobe.js`, надетые вещи — `LOOK`; надевать только через `equip()`. Новая вещь = запись в `ITEMS` (+ новый `kind` в функции слота, если нужен). Достижения выдают наборы `ACH_SETS` через `unlockSet()`. Рулетка честная: редкость по весам `RARITY`, потом любая вещь редкости, без защиты от повторов — так задумано.
- **Монеты и рекорды.** `finishRun()` (`core/meta.js`) считает очки `runScore()` и монеты `runCoins()`, пишет `META.best` и `META.top`, отправляет рекорд в общий рейтинг (`core/online.js`, Supabase; при пустых `ONLINE.url/key` всё работает локально). SQL базы — `tools/leaderboard.sql`.
- **Высота экрана — `VH`, не `innerHeight`.** iPhone с главного экрана занижает `innerHeight` на вырез сверху; `core/canvas.js` считает настоящую высоту и отдаёт разницу в CSS как `--appX`. Элементы, прибитые к низу (`bottom:`), должны вычитать `var(--appX,0px)`.
- **Состояние** (`state`): `menu | pact | play | craft | pick | pause | dead`, менять только через `setState()` (он же пишет `body[data-state]` для CSS).
- Логика идёт фиксированными шагами 60 раз в секунду (`main.js`), все таймеры в тиках.
- **Телефон.** Страница прибита к экрану (`css/mobile.css` + глушилка жестов в `core/touch.js`): прокручиваться может только `.box` окна. Не добавлять элементы, которые вылезают за край экрана, — `npm test` это проверяет на каждом скриншоте.
- **Звук** включается только по касанию: `audioInit()` висит на каждом нажатии (`core/audio.js`) и будит `AudioContext`, пока тот не заиграет; при сворачивании звук замораживается. `navigator.audioSession.type = 'playback'` — чтобы на iPhone играло и при переключателе «Без звука».
- **PWA.** `manifest.webmanifest` + `sw.js` (свои файлы сначала из сети, без сети из кэша) + `ui/install.js` (регистрация, докладывает в кэш всё загруженное, кнопка «Установить» в настройках). Новые файлы в кэш попадают сами, список вести не нужно.
- Сохранения — `localStorage` (настройки и костюмы), всегда в `try/catch`.

## Разработка и проверка

```bash
npm install      # один раз: ставит puppeteer-core (браузер не качает, берёт установленный Chrome)
npm run dev      # локальный сервер http://localhost:8080 (+ адрес для телефона в той же Wi-Fi)
npm test         # смоук-тест: ПК, телефон боком и стоя — старт, гардероб, рулетка, рекорды, пакт, бег, рывок, бой, мастерская, уровень, пауза, смерть
```

`npm test` падает на любой ошибке JS в консоли. Перед каждым профилем он чистит `localStorage`, покупает навык в дереве и отдельно гоняет забег со всей прокачкой на максимуме. Скриншоты каждого шага — в `tools/out/` (в git не попадают): смотреть их после правок вёрстки. Игровые переменные глобальные, поэтому в тесте их можно читать и менять напрямую через `page.evaluate('player.hp = 1e9')`.

`node tools/icons.mjs` перерисовывает иконки приложения из спрайта мага.

## Деплой

Пуш в `main` → GitHub Pages сам публикует (Settings → Pages → Deploy from a branch → `main` / root). `.nojekyll` отключает обработку Jekyll. Пути только относительные, имена файлов в нижнем регистре (Pages чувствителен к регистру).
