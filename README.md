# Маг Хаоса

Собирай руны, склеивай из них навыки и устраивай вакханалию. Каждый забег — новый мир и новый пакт. За забеги дают 💠 осколки хаоса — на них в главном меню прокачивается маг: 24 навыка в четырёх ветках (Сила, Стойкость, Ловкость, Знания). Шесть миров, семь боссов, 33 формы навыков.

Ещё за каждый забег дают 🪙 монеты: на них в гардеробе покупаются шляпы, мантии, посохи, сапоги, следы, глаза и бороды, а в рулетке выбиваются вещи, которых нет в магазине — от ведра на голову до радужной бороды. Таблица рекордов хранит лучшие забеги, а если подключить базу (ниже) — показывает общий рейтинг всех игроков.

Играть: https://curstfear.github.io/chaos-mage/ — работает на ПК и с телефона в браузере.

- **ПК:** WASD — бег, мышь — прицел, Space — рывок, Tab — мастерская, Esc — пауза.
- **Телефон:** веди пальцем по экрану — бег, тап по экрану — рывок в ту сторону, навыки сами бьют ближайшего врага, 🔮 — мастерская, ⏸ — пауза. Играть можно и стоя, и боком. Через «На экран „Домой“» игра открывается на весь экран.

Разработка: `npm install`, `npm run dev`, `npm test`. Устройство кода — в [CLAUDE.md](CLAUDE.md).

## Общий рейтинг

GitHub Pages умеет только отдавать файлы, поэтому рекорды всех игроков хранятся в бесплатной базе [Supabase](https://supabase.com). Пока она не подключена, в «Рекордах» видны только свои забеги.

1. Зарегистрироваться на supabase.com → **New project** (любое имя и пароль, регион поближе).
2. В проекте: **SQL Editor** → вставить всё из [`tools/leaderboard.sql`](tools/leaderboard.sql) → **Run**.
3. **Project Settings → API**: скопировать **Project URL** и публичный ключ (**anon** / **publishable**, не `service_role` и не secret!).
4. Вписать их в начало [`js/core/online.js`](js/core/online.js): `const ONLINE = { url: 'https://xxxx.supabase.co', key: '...' };` и запушить.

Публичный ключ можно держать в коде: прямого доступа к таблице у него нет, а функции из `leaderboard.sql` только поднимают рекорды и только для того, кто их поставил. Подделать свой результат через консоль браузера всё же можно — для игры среди друзей этого хватает.
