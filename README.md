# Маг Хаоса

Собирай руны, склеивай из них навыки и устраивай вакханалию. Каждый забег — новый мир и новый пакт.

Играть: https://curstfear.github.io/chaos-mage/ — работает на ПК и с телефона в браузере.

- **ПК:** WASD — бег, мышь — прицел, Space — рывок, Tab — мастерская, Esc — пауза.
- **Телефон:** палец слева — джойстик, навыки сами бьют ближайшего врага, палец справа — ручной прицел, тап справа или 💨 — рывок, 🔮 — мастерская, ⏸ — пауза. Через «На экран „Домой“» игра открывается на весь экран.

Разработка: `npm install`, `npm run dev`, `npm test`. Устройство кода — в [CLAUDE.md](CLAUDE.md).
